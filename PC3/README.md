# PC3 - Control de Procesos

Carpeta ordenada para los scripts de la Practica Calificada 3.

## Archivos

1. `01_PC3_2025_II_Pregunta_1_IMC_Linealizacion.m`: linealizacion, controlador IMC y discretizacion.
2. `02_PC3_2025_II_Pregunta_2_Desacoplamiento_MIMO.m`: sistema MIMO y controlador por desacoplamiento.
3. `03_PC3_2025_I_Pregunta_1_LQG_Cascada.m`: desacoplamiento, LQG y control en cascada.
4. `04_PC3_2025_I_Pregunta_2_HInfinito_IMC_Tanque.m`: linealizacion de tanque, control H-infinito e IMC.

Los nombres tienen prefijos numericos para mantener el orden de lectura y ejecucion.
